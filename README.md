# 可复算活动预算表

一个面向学生社团的校园活动预算管理工具，纯静态网页，无任何外部依赖。

## 功能

- **明细管理**：新增 / 编辑 / 删除预算明细（名称、分类、数量、单价）
- **自动计算**：每行小计 = 数量 × 单价，实时更新
- **分类小计**：按分类汇总金额
- **基础合计**：所有明细之和
- **备用金**：可配置百分比（0–100%），自动计算备用金金额 = 基础合计 × 比例
- **预算总额**：基础合计 + 备用金金额
- **输入校验**：负数、非数字输入标红提示，不产生 NaN
- **本地保存**：数据自动存入浏览器 localStorage，刷新 / 关闭后恢复
- **CSV 导出**：导出含 Excel 公式的 CSV（小计列写 `=C2*D2`，合计写 `=SUM(...)` 等），用 Excel / WPS / LibreOffice 打开后按 **F9** 重新计算即可得到完整结果
- **表格输入保护**：名称等文本以 `= + - @` 开头时作为文字导出，避免被表格软件执行为公式
- **响应式**：适配手机与电脑屏幕
- **示例数据**：首次打开自动载入社团活动示例

## 使用方法

1. 用浏览器直接打开 `index.html` 即可使用，无需安装任何软件。
2. 点击「新增明细」添加预算项，直接在表格中编辑名称、分类、数量、单价。
3. 在底部「备用金配置」中调整百分比。
4. 点击「导出可复算 CSV」下载文件，用表格软件打开后按 F9 复算公式。

## CSV 公式说明

导出的 CSV 中，小计列不写死数值，而是写 Excel 公式：

```
名称,分类,数量,单价(元),小计(元)
社团招新午餐,餐饮,30,25.00,=C2*D2
活动场地租赁,场地,1,500.00,=C3*D3
...
餐饮小计,,,,=E2
场地小计,,,,=E3
...
基础合计,,,,=SUM(E2:E8)
备用金比例(%),,,,10
备用金金额,,,,=E19/100*E18
预算总额,,,,=E18+E20
```

打开后需按 F9（Excel）或 Ctrl+Shift+F9 强制重新计算，公式才会显示为数值。
分类小计只引用该分类的明细行；基础合计与备用金公式使用导出时实际行号。具体行号取决于分类数量。

## 技术约束

- 纯前端，无后端、无云服务、无外部 API
- 无第三方库，无 CDN 引用
- 数据仅存于浏览器本地，不上传任何服务器
- 可运行 `node --test planner.test.cjs` 检查页面计算和 CSV 引用
